# 概要

塾選ポータルにログイン後に表示するホーム画面についてやヘッダー・ナビゲーションなどの共通UIについて記載する。

# 要件

- Phase 1ではホーム画面は作らない
- ログインするアカウントのロールにより、ホーム画面として初期表示する画面をコントロールする
- ヘッダーとナビゲーションは用意するが、フッターは作らない
- ヘッダー内にユーザーメニューを作成する

# 機能仕様
