# 概要

クライアント企業のユーザーが塾選ポータルにログインするためのアカウントを管理する。

# 要件

- アカウントは2種類存在する
    - クライアントマスターアカウント（親アカウント）
    - クライアントアカウント（子アカウント）
- クライアントマスターアカウントは、塾選の担当者がDirectus上で新規登録する
    - クライアント管理画面上ではクライアントマスターアカウントは発行させない
    - クライアントマスターアカウントのログイン情報の共有は、塾選の担当者がクライアントにメール等で共有する
- クライアントマスターアカウントは管理者ロール

# 機能仕様

## HOME画面

ログインしているユーザーのロールに合わせて、初期画面を表示する

| ユーザーロール | 画面名 | Ph1では以下 |
| --- | --- | --- |
| 管理者 | アカウント一覧 | アカウント一覧 |
| ブランド責任者（Ph2） | ブランド管理（Ph2） | お問い合わせ一覧 |
| 教室責任者（Ph2） | 教室一覧（Ph2） | お問い合わせ一覧 |
| 教室編集者（Ph2） | 教室一覧（Ph2） | お問い合わせ一覧 |

| お問い合わせ担当者 | お問い合わせ一覧 | お問い合わせ一覧 |

## ヘッダー

- 塾選ポータルのロゴを表示する
    - ロゴを押下でHOME画面に遷移する
- ログイン中のユーザー情報を表示する
    - `法人名` + ログイン中の`ユーザー名`
    - ホバーで[ユーザーメニュー](https://app.notion.com/p/3c6e2a3ec6ba806aa3fee064f5011be9?pvs=21) を表示する
