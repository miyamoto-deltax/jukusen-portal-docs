# 機能概要

法人に所属するアカウントの管理を行う。

Admin画面のクライアントアカウント管理機能で、親となるマスターアカウント（管理者ロール）が発行されている。

その子となるクライアントアカウントの新規作成・編集・削除が可能。

## 担当ブランド

同法人が運営しているブランド毎に担当が決められているケースに対応するために追加。

担当ブランドは、ユーザーアカウントに設定する。

担当ブランドは、1アカウントに複数設定可能とする。

ユーザーアカウントは、担当ブランドとして設定されているブランドの情報のみ閲覧・編集が可能となり、担当ブランドではない教室の情報はいっさいみれないようにする。

管理者ロールは全ブランドの情報が扱えるため、担当ブランドの設定は不要。

担当ブランドと担当教室はどちらかのみ設定可能とする。

## 担当教室

担当教室は、ユーザーロールではなく、ユーザーアカウントに設定する。

担当教室は、1アカウントに複数設定可能とする。

ユーザーアカウントは、担当教室として設定されている教室の情報のみ閲覧・編集が可能となり、担当教室ではない教室の情報はいっさいみれないようにする。

ただし、管理者ロールのユーザー（クライアントマスターアカウント）は全ブランドの全教室の情報を閲覧・編集を可能とするため、担当教室の設定は不要。

ブランド編集者ロールは、教室情報・請求情報の権限を持たないため、担当教室の設定は不要とする。

教室責任者・教室編集者のロールは、担当教室を`必須`とする。

担当ブランドと担当教室はどちらかのみ設定可能とする。

- 閉校した教室は設定されている担当教室情報から消すべきか？
    - 消さないで残す
    - 新規で付与も可能とする
    - 過去情報を閲覧できるようにする必要があるため
- 法人付け替えバッチは何かしら対応が必要か？
    - 特に追加対応はいらなそう

    - 必須
