# Home画面&共通パーツ

作成日時: 2023年11月10日 17:29
タグ: Phase1

# 目的

Phase1リリース時点でのHome画面とヘッダーなどの共通パーツの仕様について整理する。

# Goals & Non-Goals

## Goals

Phase1リリース時点でのHome画面と共通パーツの仕様が整理されていること。

Phase2以降に必要になる追加仕様等がある場合は、それらも含めて記載されていること。

## Non-Goals

このドキュメントでは、システムの詳細設計については語らない。

# 機能概要

ログイン後に表示するHome画面とヘッダー、ナビゲーションなどの全画面に表示する共通パーツ。

表示している環境をわかりやすくするため、ヘッダーは各環境（Prod、STG、Dev）で背景色を変えて表示する。

### ナビゲーションの権限による制御

権限がない機能については非表示にするのではなく、非活性とし各画面に遷移できないようにする。

非活性で表示をしたほうが、このシステムに何の機能があるのかの認知ができるのと、扱える誰かがいるということを認識できるため。

権限については[アカウント管理](https://app.notion.com/p/5098824c05524e348d63fcba1598675b?pvs=21)を参照。
