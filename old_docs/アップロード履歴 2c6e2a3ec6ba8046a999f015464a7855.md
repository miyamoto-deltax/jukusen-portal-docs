# 機能概要

# 機能要件

## アップロード履歴一覧

アップロードした履歴とステータスを一覧表示する。

表示する履歴は過去30日とする。

ページングは不要。

並び順は日付降順。

| 項目名 | 画面表示時の型 | datahub | memo |
| --- | --- | --- | --- |
| 日時 | datetime | - | アップロードが実行された日時。<br>YYYY-MM-DD HH:ii:ss |
| アカウントID | integer | - | アップロードを実行したアカウントのID。 |
| 表示名 | string | - | アップロードを実行したアカウントの表示名。 |
| アップロード種別 | string | - | アップロード対象の種別名。<br>~~・お問い合わせ一覧<br>・請求一覧<br>・請求対象一覧<br>・請求対象教室一覧<br>・通知先メールアドレス一覧<br>・通知先グループ一覧~~<br>・通知先メールアドレス<br>・通知先グループ<br>・通知先グループメールアドレス<br>・デフォルト通知先設定<br>・教室通知設定 |
| ファイル | string | - | アップロードしたファイル名。<br>リンクはなし。 |
| アップロードステータス | string | - | 実行状況に応じて以下を表示する。<br>・実行待ち<br>・実行中<br>・完了<br>・エラー |
| メッセージ | string | - | ステータスが完了の場合以下をテキストリンクで表示する。<br>テキストリンクを押下で[アップロードエラー一覧](https://app.notion.com/p/34ce2a3ec6ba80509727fd3b0cd3664c?pvs=21) を別タブで開く。<br>`アップロードを完了しましたが、一部のデータにエラーがありました。`<br><br>ステータスがエラーになった場合、共通エラーメッセージを表示する。<br>行エラーが記録されている場合は、共通エラーメッセージに続けて詳細リンクを表示する（2026-09-03 決着）<br>https://docs.google.com/spreadsheets/d/1A5ESCPR90tusg0g3Y4u76JpsGwIjl7qovkslaiOPPaE/edit?gid=36050624#gid=36050624&range=A54 |

## アップロードエラー一覧

CSVアップロードを実行した結果、エラーなどの理由で一部の行がスキップされることがある。

スキップされた具体的な行数と理由を一覧表示し、CSVの内容の修正に役立ててもらう。

| 項目名 | memo |

| 表示名 | 表示する値は[アップロード履歴一覧](https://app.notion.com/p/2c6e2a3ec6ba802eaaecf62fc189cf05?pvs=21) を参照。 |
| アップロード種別 | 表示する値は[アップロード履歴一覧](https://app.notion.com/p/2c6e2a3ec6ba802eaaecf62fc189cf05?pvs=21) を参照。 |
| ファイル | 表示する値は[アップロード履歴一覧](https://app.notion.com/p/2c6e2a3ec6ba802eaaecf62fc189cf05?pvs=21) を参照。 |
