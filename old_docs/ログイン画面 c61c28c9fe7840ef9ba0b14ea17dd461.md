# 機能概要

クライアント管理画面にログインするためのログイン画面。

ログインにはログインID（メールアドレス）とパスワードを用いる。

# 機能要件

- Admin画面で発行されたクライアントマスターアカウント（親）でログインが可能
- クライアントマスターアカウント（親）で、ログイン後に発行されたクライアントアカウント（子）でログインが可能
- アカウント登録時に設定したログインID（メールアドレス）とパスワードの組み合わせで認証する
- ~~SSOでのログインを可能とする~~

        - ~~Facebook（？）~~
- パスワードを忘れた場合、自身でパスワードの再設定を可能とする。
    - 登録済みのメールアドレスを入力し、自動発行したパスワードを入力されたメールアドレス宛に送信する。
    - パスワードリセット後の初回ログインは[初期パスワード変更画面](https://www.figma.com/design/Uo5ifHxfbE47NA1zNfPjhy/00_%E5%A1%BE%E9%81%B8_%E3%82%AF%E3%83%A9%E3%82%A4%E3%82%A2%E3%83%B3%E3%83%88%E7%AE%A1%E7%90%86%E7%94%BB%E9%9D%A2?node-id=180951-28915&t=TFPNoopH70dULBed-4)に遷移し、パスワード変更を必ず行うこととする。

## 入力項目

- メールアドレス
- パスワード

## バリデーション

- メールアドレス
    - 必須
    - メールアドレス形式の半角英数字
    
    - 100文字以内

- パスワード
    - 必須
    - 半角英数字と記号
    - 1つ以上の記号と、大文字小文字の組み合わせ
    - 8文字以上100文字以内
- Session
    - 24時間とする

## パスワードリセット

~~ログインパスワードを忘れてしまった場合に、パスワードリセット依頼のメールを管理者に送信する。~~

ログインパスワードを忘れてしまった場合は、自身でパスワードの再設定を可能とする。

登録済みのメールアドレスを入力し、自動発行したパスワードを入力されたメールアドレス宛に送信する。

パスワードリセット後の初回ログインは[初期パスワード変更画面](https://www.figma.com/design/Uo5ifHxfbE47NA1zNfPjhy/00_%E5%A1%BE%E9%81%B8_%E3%82%AF%E3%83%A9%E3%82%A4%E3%82%A2%E3%83%B3%E3%83%88%E7%AE%A1%E7%90%86%E7%94%BB%E9%9D%A2?node-id=180951-28915&t=TFPNoopH70dULBed-4)に遷移し、パスワード変更を必ず行うこととする。
